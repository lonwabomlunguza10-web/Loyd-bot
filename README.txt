LOYD BOT PWA PROTOTYPE 0.3

New in version 0.3:
- Chart Scanner interface (demo-only; no live chart feed or real analysis yet).
- Proposed subscription plan: USD $10 per month (checkout is not connected; no payment is taken).

Android install:
1. Host all files on an HTTPS static website host.
2. Open the hosted site in Chrome on Android.
3. Chrome menu > Install app / Add to Home screen.

Important:
- This is a PWA project, not a standalone APK.
- Scanner results are illustrative and must not be used to make trading decisions.
- No MT5 connection, live signals, automatic trading, or payment processing is connected.
- Before charging customers, add a secure payment provider, subscription management, clear cancellation/refund terms, privacy policy, and secure authentication.
- Subscription price is proposed at USD $10/month; confirm local currency display, taxes and fees before launch.
